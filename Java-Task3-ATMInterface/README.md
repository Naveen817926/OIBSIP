# ATM Interface

## Project Overview

The ATM Interface is a console-based Java application that simulates basic ATM banking operations. It allows users to securely log in using a User ID and PIN and perform different banking transactions.

## Features

- User ID and PIN authentication
- Maximum 3 login attempts
- Check account balance
- Deposit money
- Withdraw money
- Transfer money
- View transaction history
- Input validation
- Secure logout and exit
- Transaction records using ArrayList

## Technologies Used

- Java
- Object-Oriented Programming (OOP)
- ArrayList
- Java Collections
- LocalDateTime
- Scanner

## How to Run

1. Open the project in any Java-supported IDE such as VS Code, IntelliJ IDEA, or Eclipse.
2. Compile all Java files.
3. Run `Main.java`.
4. Enter the User ID and PIN.
5. Select an option from the ATM menu.
6. Perform the required banking transaction.
7. Select Exit to close the application.

## ATM Operations

After successful login, the user can:

1. Check Balance
2. Deposit Money
3. Withdraw Money
4. Transfer Money
5. View Transaction History
6. Exit
